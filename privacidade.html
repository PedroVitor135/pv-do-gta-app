Política de Privacidade — PV DO GTA Uploader

Última atualização: 11 de novembro de 2026

O PV DO GTA Uploader ("a ferramenta") é de uso pessoal e interno do canal PV DO GTA no YouTube e é usado apenas pelo próprio dono do canal.

Uso dos Serviços de API do YouTube

A ferramenta usa os Serviços de API do YouTube. Ao usar a ferramenta, você concorda em ficar vinculado aos Termos de Serviço do YouTube. O tratamento de dados pelo Google é regido pela Política de Privacidade do Google.

Dados acessados, coletados e armazenados

  • Permissões (escopos OAuth): youtube.upload (enviar vídeos ao canal) e youtube.readonly (ler o nome do canal autorizado e confirmar o status dos vídeos enviados).
  • Dados da API usados: nome e ID do canal do próprio dono; ID, título, descrição, status de privacidade e horário de publicação dos vídeos enviados pela ferramenta.
  • Dados de terceiros: nenhum. A ferramenta não acessa dados de espectadores, comentários, inscritos ou outros canais.

Como os dados são usados

Exclusivamente para enviar, agendar e confirmar os vídeos do canal PV DO GTA. Os dados não são vendidos, compartilhados, transferidos ou usados para publicidade.

Armazenamento e compartilhamento

O token de autorização OAuth e um registro com o ID e o link dos vídeos enviados ficam armazenados somente no computador do dono do canal. A ferramenta não possui servidores próprios e não envia dados a terceiros. A ferramenta não usa cookies.

Exclusão de dados e revogação do acesso

O acesso pode ser revogado a qualquer momento na página de permissões de segurança do Google: security.google.com/settings/security/permissions. Ao revogar o acesso ou deixar de usar a ferramenta, o token e o registro local são apagados do computador em até 7 dias. Os dados obtidos da API nunca são guardados por mais de 30 dias sem serem atualizados ou apagados.
