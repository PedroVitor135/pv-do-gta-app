Política de Privacidade — PV DO GTA Uploader

Última atualização: 11 de novembro de 2026

O PV DO GTA Uploader é uma ferramenta de uso pessoal e interno do canal PV DO GTA no YouTube. Ela é usada apenas pelo próprio dono do canal para enviar e agendar vídeos no seu canal pela API de Dados do YouTube (YouTube Data API v3).

Dados acessados

A ferramenta acessa somente a conta do YouTube do próprio dono do canal, com a permissão de enviar vídeos (youtube.upload) e de ler as informações básicas do canal (youtube.readonly). Nenhum dado de outras pessoas ou de espectadores é coletado.

Uso dos dados

Os dados são usados exclusivamente para enviar, agendar e confirmar a publicação de vídeos no canal PV DO GTA. Não há venda, compartilhamento ou transferência de dados para terceiros.

Armazenamento

O token de autorização fica armazenado apenas no computador do dono do canal. Nenhum dado é enviado para servidores próprios.

Revogação do acesso

O acesso pode ser revogado a qualquer momento em myaccount.google.com/permissions.

Serviços do YouTube

Esta ferramenta usa os Serviços de API do YouTube. Ao usá-la, valem os Termos de Serviço do YouTube e a Política de Privacidade do Google.
