PV DO GTA Uploader

Desenvolvido com os Serviços de API do YouTube

Ferramenta de uso pessoal e interno do canal PV DO GTA no YouTube. Ela envia e agenda os Shorts produzidos pelo próprio dono do canal, usando a API de Dados do YouTube (YouTube Data API v3), com título, descrição e horário de publicação definidos pelo dono do canal.

Como funciona

  1. O dono do canal autoriza a ferramenta uma única vez pela tela oficial de login do Google (OAuth 2.0).
  2. Todos os dias, a ferramenta envia os vídeos já editados do computador do dono para o próprio canal, como privados e agendados.
  3. O dono pode revisar, alterar ou cancelar cada vídeo no YouTube Studio antes do horário agendado.

A ferramenta não é oferecida ao público, não acessa contas de outras pessoas e não exibe conteúdo do YouTube.
